# Ekd5 引擎 `.e5` 文件格式研究笔记

本文记录对本仓库 `kw/` 目录（曹操传 MOD 版游戏包）文件格式的验证结果。
Ls11/Ls12 容器与解压算法为社区公开逆向成果（轩辕春秋论坛 van、Maxwell 等人，
参考实现见 GitHub 的 LSReader 等项目）；本仓库内的解析代码均为原创实现。
以下所有条目均在本仓库文件上**实测验证通过**，标注「推测」的除外。

## 1. Ls11 / Ls12 封包容器

| 偏移 | 长度 | 含义 |
|------|------|------|
| 0x000 | 16 | 标识 `"Ls11"` 或 `"Ls12"` + 12 字节填充（空格） |
| 0x010 | 256 | 解压字典（单字节查表） |
| 0x110 | 12×n | 条目表：大端 u32 ×3 = 压缩长度、原始长度、数据偏移；压缩长度为 0 表示表结束 |
| — | — | 条目数据区 |

- 压缩长度 == 原始长度 ⇒ 该条目未压缩，直接存储。
- 解压算法（MSB 位流，变长码）：
  1. 读取变长码：连续读位直到读到 0（含终止位共 n 位）得前缀值 `code1`，再读 n 位得 `code2`，码值 = `code1 + code2`。
  2. 码值 < 0x100 ⇒ 输出 `dictionary[码值]`。
  3. 码值 ≥ 0x100 ⇒ 回溯复制：偏移 = 码值 − 0x100，长度 = 下一个变长码 + 3，从已解压数据处回拷（允许重叠）。

工具：`tools/e5tool.py`（list / unpack / info / map），Unity 运行时读取器 `kw_cursor/Assets/Scripts/Import/E5Archive.cs`。

## 2. 已验证的文件

### hexzmap.e5 — 战场地形数据（Ls12，87 个条目）

每个条目 = 一张战场地形图：

| 偏移 | 长度 | 含义 |
|------|------|------|
| 0 | 1 | 地图宽 × 3 |
| 1 | 1 | 地图高 × 3 |
| 2 | w×h | 地形 ID（行主序，每格 1 字节） |

实测：条目 0 为 20×20（第一关），与 `Hm00.e5` 战场画面逐格对应。
全库常见地形 ID 频度（降序）：0、4、13、16、2、1、7、15、5、14、23、12、3、25、10…
已确认语义：`0` 平原类、`4` 山体；`20/22/24` 营帐建筑、`14/23` 栅栏（对照战场图观察）。
其余 ID 语义待与 Data.e5 地形表对照校准。

### Hm??.e5 — 战场画面（未封包，裸图块流，已完全破解）

- 内容 = 对应关卡地图的 `w×h` 个图块，行主序；每图块 **96×24 像素、8bpp 调色板索引**，2304 字节。
- 文件大小 = w×h×2304（部分文件尾部多 2 字节 `00 00` 填充）。
- 格子为**轴对齐矩形，奇数行无半格偏移**（以帐篷/栅栏像素覆盖率对「对齐/右移半格」两种假设计分验证，对齐胜出）。
- 完整画面 = (w×96) × (h×24) 像素；文件序号与 hexzmap 条目序号一致（本仓库存在 Hm00–58 中的 53 个）。
- 渲染验证：`python3 tools/e5tool.py hmrender kw <序号> out.png`（多张地图颜色/结构均正确）。

### Spalet.e5 — 战场调色板（Ls12，78 个条目，已破解）

- 每条目 768 字节 = 256 色 × 3 字节（条目 15 为 738 字节略短，读取时按可用长度取）。
- **字节序（实测）**：存储三元组 (b0,b1,b2) → 显示 (R,G,B) = **(b1,b2,b0)**。
  按 R,G,B 直读会得到蓝色调错误画面（曾被误判为"夜战"配色）。
- 与地图按同序号对应（78 张调色板 / 87 张地图，越界取末张——该启发式可再校准）。
- 调色板按亮度渐变组织（这也是此前灰度渲染看起来正常的原因）。

### Face.e5 — 武将头像（Ls12，505 条目，已破解）

- 每条目 64×80 像素 8bpp（5120 字节；部分带 2 字节 `00 00` 尾，共 5122）。
- 调色板：专用调色板尚未精确定位，用 `Pmpalet.e5` 条目 0（同上字节序）渲染肤色/盔甲自然。
- 武将表偏移 15 的头像编号即本封包条目序号。

### Pmpalet.e5 / Logo_p.e5 — 其他调色板

- `Pmpalet.e5`：Ls12，154 条 × 768 字节（内场景/界面调色板组）。
- `Logo_p.e5`：Ls12，4 条（Logo 用）。`*_p` 命名 = 对应图像文件的调色板。

### Smlmap.e5 — 战场小地图（Ls12，78 条，已破解）

- 每条 = 地图 **(w×6) × (h×6) 像素 8bpp**（每格 6×6 像素），行主序。
- 调色板与战场画面共用 `Spalet.e5` 同序号条目；实测渲染正确。
- 工具：`python3 tools/e5tool.py smlrender kw <序号> out.png`。

### Pmapobj.e5 — 单位小人图（Ls12，520 条，已破解）

- 每条 = **20 帧 48×64 像素 8bpp 动作图**（61440 字节，部分带 2 字节尾），帧序竖排。
- 帧序实测：0–2 为连续步态；3 为下蹲/受击；4–8 多为攻击/施法姿势；
  9–19 因形象而异且可能为空帧。Unity 当前用 0–2 循环行走，左右镜像，4–8 播放攻击/策略动作。
- **透明键 = 索引 0**（对应调色板中的洋红占位色）；调色板用 `Pmpalet.e5` 条目 0。
- 武将表偏移 13-14 的形象编号即条目序号（实测形象最大值 495 < 520 ✓，
  之前怀疑"形象文件缺失"是误判——就在本文件里）。
- 工具：`python3 tools/e5tool.py unitrender kw <形象号> out.png`。

### Item.e5 — 道具图标（Ls12，126 条，已接入）

- 每条 1024/1026 字节 = **32×32 像素 8bpp**，透明键 = 0，调色板用 `Pmpalet.e5[0]`。
- Data.e5 道具表实际为 2600 / 25 = **104 条**；Item.e5 多出的 22 张为界面/备用图标。
- 已实测渲染剑、枪、衣甲、圆盾等图标，并接入单位信息面板装备栏。
