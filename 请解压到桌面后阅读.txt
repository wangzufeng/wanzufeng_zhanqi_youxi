万祖峰战棋复刻 —— 请把本文件夹放到桌面

这个压缩包是 Unity 工程源码，不是安装包。
云端助手写不了你电脑的桌面，所以请你本地下载后放到桌面。

放到桌面的两种办法
------------------
方法 A（推荐）
  1. 在 Cursor 右侧文件树找到：战棋复刻-请解压到桌面.zip
  2. 右键 → Download / 下载（不要双击打开，那会提示 Binary 无法预览，正常）
  3. 浏览器下载完成后，把 zip 拖到桌面
  4. 右键 zip → 解压到当前文件夹（或 Extract Here）
  5. 桌面上会出现文件夹「战棋复刻」

方法 B
  若 zip 下到了「下载」文件夹：进入解压后的「战棋复刻」，双击「放到桌面.bat」

如何用 Unity 打开
----------------
1. 安装 Unity Hub，安装 Unity 2021.3 或更新版本
2. Unity Hub → Add → 选桌面上的 战棋复刻\kw_cursor
3. 菜单：战棋复刻 → 1. 生成并保存战斗场景
4. 把原版游戏文件夹 kw 放到与 kw_cursor 同级（即 战棋复刻\kw）
   你已有的 GitHub 仓库 wangzufeng/wanzufeng_zhanqi_youxi 里就有 kw
5. 菜单：战棋复刻 → 3. 导入原版数据
6. 点 Play

本包不含原版 kw（约 647MB），请从你自己的游戏仓库复制。
包内有：kw_cursor（Unity 工程）、tools、docs、README.md
