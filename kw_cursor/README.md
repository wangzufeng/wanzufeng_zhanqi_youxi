# 战棋复刻 Demo（Unity，安卓 / iOS）

本目录是一个**完整的 Unity 工程**，用 Unity Hub 打开即可运行。它复刻了 `kw/` 中经典战棋游戏（Ekd5 引擎）的**核心战斗玩法框架**：六角格地图、地形加成、兵种相克、回合制移动 / 攻击 / 策略 / 待机、反击、敌方 AI，并针对手机做了触屏与横屏适配。

## 为什么不是「逐像素完美复刻」

必须说明清楚，避免误解：

1. `kw/` 内是**闭源成品**：`Ekd5.exe` 加专有二进制格式 `.e5`（地图、立绘、数据全部封装在内），**没有任何可移植的源码**。逐像素复刻需要对引擎和数据格式做完整逆向工程，这是一个长期工程。
2. 原版的图像、音乐、剧本文本**受版权保护**，不能直接复制进新工程。本工程的画面全部由**代码程序化生成**（占位棋子与地形色块），剧情台词为**原创撰写**（背景取材于公有领域的东汉黄巾之乱史实），不包含原作任何素材。
3. 本工程复刻的是**规则与手感的骨架**，数值为近似实现（见下文「与原版的差异」），全部集中在数据表里，方便逐步校准。

## 环境要求

- Unity Hub + **Unity 2021.3 LTS 或更新版本**（建议 2022.3 LTS）
- 打包安卓：在 Unity Hub 安装编辑器时勾选 **Android Build Support**（含 SDK & NDK、OpenJDK）
- 打包 iOS：需要 **macOS + Xcode**，Unity 侧勾选 iOS Build Support

## 如何打开运行

1. 打开 Unity Hub → `Add`（添加项目）→ 选择本目录 `kw_cursor/`。
   - 如提示缺少版本信息，选择你已安装的 2021.3+ 版本打开即可（首次导入会自动生成 `Library/`、`ProjectSettings/`）。
2. 打开工程后，菜单栏点击 **战棋复刻 → 1. 生成并保存战斗场景**（生成 `Assets/Scenes/Battle.unity` 并加入 Build Settings）。
3. 点击 **Play** 即可开始演示战斗（工程采用运行时自举，空场景也能直接 Play）。

## 如何打包手机版

### Android（APK）

1. 菜单 **战棋复刻 → 2. 应用移动端 Player 设置**（横屏、包名等一键设置）。
2. `File → Build Settings → Android → Switch Platform`。
3. `Build`，输出 APK 安装到手机。

### iOS

1. 同样先执行菜单 1、2。
2. `File → Build Settings → iOS → Switch Platform` → `Build`，输出 Xcode 工程。
3. 用 Xcode 打开，配置签名（Team），连真机运行或走 TestFlight。

## 操作方式

| 操作 | 手机 | 编辑器 / PC |
|------|------|------------|
| 选中 / 确认 | 点按 | 鼠标左键点击 |
| 平移地图 | 单指拖动 | 左键按住拖动 |
| 缩放地图 | 双指捏合 | 滚轮 |
| 取消 | 点菜单「取消」或点空地 | 同左 |

流程：点我方武将 → 弹出指令菜单（移动 / 攻击 / 策略 / 待机 / 取消）→ 蓝色高亮为可移动格，红色为可攻击目标，紫 / 绿为策略目标。移动后未确认行动前可「取消」退回原位。

## 演示关卡

「颍川遭遇战」：曹操、夏侯惇、夏侯渊、曹洪 对阵 黄巾军六人。
**胜利条件**：击败敌将波才（或全歼敌军）；**失败条件**：曹操阵亡。

## 加载原版数据（重点功能）

本工程内置 Ls11/Ls12 封包读取器（`Assets/Scripts/Import/`），可直接读取原版数据：

1. 菜单 **战棋复刻 → 3. 导入原版数据**：自动把仓库 `kw/` 下的
   `hexzmap.e5`（地形）、`Hm00–04.e5`（战场画面）、`Spalet.e5`（调色板）、
   `Data.e5`（武将/策略/道具表）、`Face.e5`（头像）、`Pmapobj.e5`（单位动作）、
   `Item.e5`（道具图标）、`Smlmap.e5`（小地图）、`Se??.wav`（音效）、`SoundTrk` MP3（音乐）
   复制到 `Assets/StreamingAssets/kw/`（该目录被 `.gitignore` 排除，不会提交）。
2. 再次 Play：启动后自动加载——
   - **原版战场画面**（96×24 图块 + 每关调色板，原色渲染为整图背景）；
   - **原版地形网格**（真实通行/防御数据，方格四方向移动）；
   - **原版武将表**（我方 4 名武将使用真实姓名，数值由原始字段缩放）；
   - **原版头像、单位小人动作、小地图与装备图标**；
   - **原版音乐音效**（按章节选曲，攻击/治疗/阵亡等音效）。
   未导入数据时自动回退到手工演示地图（六角格），不影响运行。
3. 战役共 5 章（地图 0–4），胜利自动进入下一章并存档进度（PlayerPrefs）。
4. 命令行工具：
   - 字符画预览地形：`python3 ../tools/e5tool.py map ../kw/hexzmap.e5 <序号>`
   - 渲染原版画面 PNG：`python3 ../tools/e5tool.py hmrender ../kw <序号> out.png`
   - 导出单位 20 帧动作：`python3 ../tools/e5tool.py unitrender ../kw <形象号> out.png`

已知待校准项（不影响游玩）：地形 ID 语义映射（`TerrainIdMap`）、武将表兵种/五维字段
对应关系（`OfficerTable` / `Campaign`）、调色板与地图的对应启发式、音效编号映射
（`AudioManager.SfxMap`）。详见 `../docs/e5-format.md`。
仓库缺失剧本文件（R/S_*.eex），章节台词为原创编写。

## 已实现的玩法规则

- 尖顶六角格地图（odd-r 排布），与原作一致的六向移动
- 地形：平地 / 森林 / 山地 / 河流（不可通行）/ 村庄，影响移动消耗与防御加成；骑兵进入森林、山地额外耗移动力
- 兵种：步兵 / 骑兵 / 弓兵 / 军师，各自移动力与射程（弓兵射程 1–2）
- 兵种相克（+25% 伤害）：骑克弓、弓克步、步克骑
- 回合制：我军全员行动完毕后敌军行动；行动过的单位变灰
- 攻击结算含**反击**（防守方射程内按 75% 威力反击）
- 策略系统（MP 消耗）：火计（范围伤害单体，吃精神值）、医术（治疗友军）
- 敌方 AI：警戒范围外待机，进入后优先攻击「移动后可打到且血量最少」的目标，否则向最近我方推进
- 血条、伤害飘字、回合横幅、单位详情面板（含所站地形加成）
- 原版武将头像、单位小人站立/行走/攻击/受击动作、右上小地图
- 原版道具名称与 32×32 图标，单位信息面板显示装备
- 五章连续战役、经验升级、章节进度存档
- 触屏：点按 / 拖动 / 捏合缩放，UI 与地图点击互不冲突

## 与原版的差异（后续可迭代）

| 差异点 | 说明 |
|--------|------|
| 数值公式 | 攻防、相克、反击为近似公式，集中在 `UnitDefs.cs` / `TerrainDefs.cs`，可对照原作逐步校准 |
| 素材 | 用户本地导入原版地图、立绘、小人图、图标、音乐；未导入时使用程序化占位 |
| 剧情 | 仓库缺失 R/S 剧本文件，当前为五章原创串联台词，不能还原原作事件脚本 |
| 系统 | 已有升级/装备展示/多关卡/存档；商店、完整装备更换、道具使用尚未实现 |

## 常见问题

- **打开后控制台报错？** 请把报错信息发给维护者（或贴回对话），多数为 Unity 版本 API 差异，逐条修即可。
- **中文显示为方块？** 本工程使用动态字体回退到系统字体，Windows / macOS / Android / iOS 均自带中文字体，一般无此问题；若出现，请在 `UIFactory.DefaultFont()` 里替换为项目内自带的中文字体文件。
- **想替换成自己的素材？** 在 `SpriteFactory` 处替换为 `Resources.Load<Sprite>(...)` 加载即可；请注意素材版权。
