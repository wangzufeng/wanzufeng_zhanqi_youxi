# 战棋游戏复刻仓库

| 目录 | 内容 |
|------|------|
| `kw/` | 原版游戏成品包（Ekd5 引擎，含 MOD 数据；二进制资源） |
| `kw_cursor/` | **Unity 复刻工程**：六角战棋核心玩法 + 手机（Android/iOS）适配，可读取原版数据 |
| `tools/` | `e5tool.py`——Ls11/Ls12 封包解析工具（列表 / 解包 / 地图预览） |
| `docs/` | `.e5` 文件格式研究笔记 |

## 快速开始

1. 用 Unity Hub 打开 `kw_cursor/`（Unity 2021.3+）。
2. 菜单「战棋复刻 → 1. 生成并保存战斗场景」。
3. 菜单「战棋复刻 → 3. 导入原版数据」——自动把 `kw/hexzmap.e5` 等复制到 StreamingAssets，
   运行时即加载**真实战场地形**。
4. Play 开始游戏；打包手机版见 `kw_cursor/README.md`。

## 命令行工具

```bash
python3 tools/e5tool.py list kw/Data.e5        # 查看封包条目
python3 tools/e5tool.py map  kw/hexzmap.e5 0   # 字符画预览第 1 关地形
python3 tools/e5tool.py unpack kw/Face.e5 out/ # 解包全部条目
```
